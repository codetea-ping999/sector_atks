## 4. スキャンから分かったこと（論文に使える観察）

1. **「使うグループの割合」で重みを作ると、業種間の差は小さい。** 13 業種の上位 20 技術を比べると、Jaccard 係数は平均 0.50（最小 0.18、最大 0.74）。全業種に共通するのは T1003、T1059、T1078 の 3 つだった。上位はどの業種でも T1059（コマンド・スクリプト実行）や T1566（フィッシング）といった汎用の技術が占める。
2. **業種らしさはリフト（業種内の割合 ÷ 全体の割合）に出る。** たとえばエネルギーでは T1210（リモートサービスの悪用）、医療では T1210 と T1135（ネットワーク共有の探索）のリフトが高い。ただし対象グループ数が 8〜14 の業種（小売・宿泊・飲食、メディア、NGO、運輸）では偶然の影響が大きい。
3. **ATT&CK には「標的業種」の構造化データがない。** 記述文からの推定に頼るため、判定の根拠を残して人が修正できる形にした。これは妥当性への脅威として論文に書く必要がある。
4. **重みの選び方（割合・リフト・観測頻度）で優先順位が変わる。** 研究ノート 06 の RQ2（どの要素が順位を最も変えるか）を、このデータで具体的に検証できる。
